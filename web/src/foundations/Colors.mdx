# Colors

Everything is a CSS custom property on `:root`. Components use tokens only, never raw values. Status colour is never the only signal: every status also has an icon and a text label.

export const Swatch = ({ name, note }) => (
  <div style={{ display: 'flex', alignItems: 'center', gap: 12, margin: '6px 0' }}>
    <span
      style={{
        width: 44,
        height: 28,
        borderRadius: 6,
        background: `var(${name})`,
        border: '1px solid #3b4252',
      }}
    />
    <code>{name}</code>
    <span style={{ color: '#a3abbd' }}>{note}</span>
  </div>
);
