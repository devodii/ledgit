# Contributing

Thank you for helping keep Ledgit accurate.

## Correct or add evidence by pull request

The registry in `data/registry/` is generated by the pipeline, so do not edit it by hand. Corrections go in `data/corrections/<event>.yaml`, which the pipeline applies when it writes the registry.

Every correction needs a public `source_url` that shows the fact. Example:

```yaml
- claim_id: some-org-abc123
  source_url: https://example.com/page-that-proves-it
  note: The organisation lists this issuer on its stellar.toml.
  org: { domain: example.com, country: Exampleland }
  add_evidence:
    - { kind: asset_issuer, network: pubnet, ref: "CODE-GISSUER", found_via: "issuer listed on the organisation's stellar.toml" }
  remove_evidence:
    - { kind: anchor, network: pubnet, ref: wrong.example.com }
```

Then run `task pipeline EVENT=meridian-2025` or just the write stage:

```bash
cd api && uv run python -m receipts.cli pipeline write --event meridian-2025
```

and include the regenerated `data/registry/meridian-2025.yaml` in your pull request.

### Evidence kinds

| Kind | `ref` format |
| --- | --- |
| `asset_issuer` | `CODE-GISSUER...` or just the issuer account |
| `soroban_contract` | the `C...` contract id |
| `anchor` | the anchor domain |
| `protocol_upgrade` | `protocol-<number>` |

## Report a wrong quote or claim

Use the "Suggest a correction" link on the claim page. It opens a prefilled issue.

## Working on the code

```bash
cp .env.example .env
task up          # stack
task lint        # api and web linters
task typecheck
```

Rules we follow:

- Never invent data. A quote must be an exact substring of the stored transcript.
- Verdicts are computed by code, never typed. Wording stays neutral.
- Backend models are Pydantic. The CLI uses argparse. The database uses raw SQL, with schema changes made in `db/schema/` and applied by pgschema (`task schema:plan`, `task schema:apply`).
- Comments only where they explain a non-obvious why.
- Commits are small, one change each, in the form `type: subject` with a lowercase imperative subject and no body.
